**Purpose:** prove the Diagnoser's `summary` output reads as human-written, not AI slop.
**Acceptance (per `next-step.md` / `task-log.md`):** show **3 peers** **5 random** Diagnoser summaries **blind**; record **≥3/5 judged "human."**
