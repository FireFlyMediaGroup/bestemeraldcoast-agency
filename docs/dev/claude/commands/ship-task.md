# /ship-task

Use this command when a task is ready to finalize.

## Behavior
- Confirm the task satisfies the plan.
- Confirm the ADR still holds.
- Confirm validation has run.
- Summarize completed files.
- Record the next task or loop step.

## Response Format
- Completed task.
- Validation summary.
- ADR impact.
- Next task.
- Risks or follow-ups.
