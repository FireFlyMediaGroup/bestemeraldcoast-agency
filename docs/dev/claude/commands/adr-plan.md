# /adr-plan

Use this command when starting any new task.

## Behavior
- Read the master ADR.
- Read the master project plan.
- Identify the next task.
- Report dependencies and blockers.
- Produce a concise execution checklist.
- Do not implement until the plan is acknowledged.

## Response Format
- Current task.
- Relevant ADR sections.
- Files likely to change.
- Validation steps.
- Next task after completion.
